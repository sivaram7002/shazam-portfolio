# S. K. Sivaram (Shazam ⚡) · Noir & Crimson Cybernetic Portfolio

A high-performance personal systems architecture portfolio inspired by **[saai.pro](https://saai.pro/)**, featuring a **simulated 6-agent collaborative AI swarm**, **500 separate autonomous cursors**, and **autonomous downward-scrolling word-by-word construction** in a sleek **Noir & Crimson Op-Art** visual language.

## ⚡ Key Highlights

### 1. Noir & Crimson Op-Art Aesthetic (saai.pro Architecture)
* **Obsidian Noir & Crimson System**: Deep dark Obsidian base (`#050608`), sharp Crimson Red accents (`#e6193c`), and Electric Shazam Gold (`#f5ee38`).
* **Architectural Crosshairs (`.op-card`)**: Precise technical corner `+` crosshairs on cards, terminal box, experience panels, and 35mm film frame.
* **Brutalist Systems Typography & Buttons**: JetBrains Mono telemetry index tags (`[01 // SYSTEM ARCHITECTURE]`), condensed high-impact display titles, and crisp hairline buttons that invert to crimson on hover.
* **Ambient Op-Art Lighting**: Radial crimson ambient glow across the header and cards over a fine 32px engineering grid.

### 2. SAAI.PRO JavaScript Engines Imported Directly
* **`app.js` — Atmospheric Ambient Canvas & Interactive Modules**:
  * **Noir & Crimson Op-Art Canvas (`#aurora-canvas`)**: Smooth mouse-parallax orbital physics with deep crimson ambient gradients and concentric expanding radar rings.
  * **1-Click Email Copy & Toast Notification**: Automatically copies `sivaramsuresh2007@gmail.com` with a bottom floating toast notification (`#toast`).
  * **GPU Optimization**: Uses `IntersectionObserver` to automatically pause canvas rendering when offscreen or in background tabs.
* **`swarm-init.js` — Swarm Takeover Bootloader**:
  * Manages the lifecycle of the swarm rebuild, detects font rendering readiness, tab visibility, and automatically triggers smooth Tour mode on page load.
  * Provides keyboard shortcuts (`Esc` instantly drops the takeover to reveal the live site).
* **`swarm/swarm.js` — Multiplayer Cursor Swarm Rebuild Engine (Joel Califa / Dhvanil Patel)**:
  * Full-viewport canvas takeover that scans the live DOM layout into a blueprint.
  * Dispatches named multiplayer cursors (Ada, Linus, Grace, Alan, etc.) with custom tools: crosshair box drawers, pen-tool vector paths, typewriters, alignment snapping rulers, and alt-drag duplicates.
  * Integrated Floating HUD:
    * **Tour**: Auto-scrolls through sections as the swarm constructs them.
    * **Speed**: Toggle build velocity (1×, 2×, etc.).
    * **Sound**: Toggle generative pentatonic synthesis audio on/off.
    * **Go Live**: Instantly fades out the canvas overlay and returns full control to the live DOM.
    * **Replay**: Resets and replays the swarm build from the beginning.

### 3. Silent & High-Performance Design
* **100% Canvas GPU Acceleration**: Pre-rendered offscreen cursor sprites render 500 separate cursors at a locked 60fps/120fps with under 0.1ms frame overhead.
* **Completely Silent**: Sound effects stripped for a clean, distraction-free reading experience.
* **Instant Auto-Start**: Construction swarm initiates automatically upon page load.

### 4. Cybernetic UI & Interactive Features
* **35mm Hologram Film Reel**: Embeds `1000077731.png` with holographic scanline animation and optical shutter flash.
* **Interactive UNIX Terminal (Stack 08)**: Live shell prompt supporting commands: `help`, `bio`, `skills`, `projects`, `contact`, `shazam`, `whoami`, `quote`, `matrix`, `rebuild`, `clear`.
* **Clinical Intelligence Blueprint Modal**: Interactive architecture drawer detailing EHR chunking, RAG pipeline, and 1-page physician brief generation.
* **Control HUD Dock**: Floating widget with animated crimson pulse dot, `[500 SWARM]`, `[⚡ REBUILD]`, `[⏩ SKIP]`, and `[🌓 THEME]` (Dark/Light).

## 🚀 Quick Start / Local Preview

You can open `index.html` directly in any web browser, or serve it using Python / Node:

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js npx
npx serve
```

Then visit `http://localhost:8000` in your browser.
